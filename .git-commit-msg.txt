新增: 第五批改编——auto-chat 0.4.0 掷骰与问过即退、mood-diary 0.1.0 心情日记、memory-weekly 0.1.0 记忆回顾

六个参考仓库（private_companion / dsh-soundtry / dsh-qq-link / dsh-feiyu-mood /
dsh-speak-up / dsh-fish-memory），逐仓机制对照 soapbot 能力面改写，不照抄；
六仓逐条决策与不抄理由见 ADAPTATION.md 第五批。

- auto-chat 0.4.0：dsh-speak-up 的本地掷骰（峰时命中线 60%/谷时 20%，连败补偿
  +10 上限 +40，命中清零，零 token）+ private_companion「不机械追问」的确定性版
  （话题问过即退，片段池靠钩子换血）+ /autochat-dry 演练（与真发同源，不发送不
  推进计数）。
- mood-diary 0.1.0（新包）：feiyu-mood 的模型判心情 + prompt 注入与 soapbot 的
  「插件状态不进 prompt 权威」冲突——走日记式改编：每晚由当日交互统计确定性分档
  基调（≥15 开心/6-14 热闹/1-5 平静/0 想念），存插件加密 storage 时间线（30 天），
  /mood 查看；基调极端主动一句（每日 ≤1 条）；第一次对话周年主动一句（防重）。
  与宿主温度互补：温度管关系亲疏，日记管当日热闹程度。无模型调用。
- memory-weekly 0.1.0（新包）：fish-memory 的淡忘半衰期/事实键是宿主记忆层设计
  输入（插件只有 memory.recall），插件侧改写为 /memweek：本周话题逐个召回、按
  记忆 id 去重；召回无时间戳就不编造时间感（soundtry 诚实性原则），时间感只来自
  钩子攒话题的时间戳。无 cron 推送（跨会话召回无 caller 被宿主拒绝）。
- soundtry 整体不改编（宿主已有 transcribe 槽；2.4GB 依赖栈违背安装器轻量哲学），
  吸收诚实性三态与 doctor 自检两条原则；qq-link 不改编（桥即本体），三条宿主设计
  输入（戳一戳 notice/BV 提取/点名接听）登记进 ADAPTATION.md。
