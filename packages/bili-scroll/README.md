# bili-scroll（soapbot 插件）

每天替你刷一轮 B 站，把值得看的推给你。**零写入立场**：不点赞、不评论、不关注、
不发动态——原仓库（c1overzz/dsh-bili-scroll）的「自动评论 @你」在本仓库被明确
排除，那是拿你的账号说话。

## 0.2.0：判断基于字幕原文，而非标题摘要

c1overzz 版的核心是「读字幕原文判断价值」；宿主字幕能力面（WBI 签名，main 仓库
#52）落地后，这个思想能落了：

- 标题/简介关键词命中（−标题党标记）做**初筛**；
- 初筛前 6 条经宿主 `bilibili.subtitle` 取**字幕原文**，关注词在字幕里命一次 +2
  加权重排——判断看的是「视频说了什么」，不是标题党会不会写；
- 无字幕 / 抓取失败 → 降级用标题分（原仓库的降级链是字幕→抽帧→跳过，我们的
  能力面没有画面抓取，降级终点是标题分，如实写在代码里）。

日报格式改为 c1overzz 的「段首固定 `### BV号`」+「为什么值得」一行——段首可
grep，统计不靠猜。

## 命令

| 命令 | 作用 |
|---|---|
| `/bili-scroll-set <逗号分隔关键词>` | 配置关注词与投递会话（留空用默认） |
| `/bili-scroll-now` | 现在刷一轮（无视作息窗口） |
| `/bili-scroll-forget` | 清空已推荐去重记录 |

## 克制机制

| 机制 | 内容 |
|---|---|
| 作息窗口 | cron 只在 20:00-24:00 抓取（whale 的生物钟思想） |
| 读预算 | 每轮热门列表 + 元数据 ≤12 次 |
| 风控退避 | 撞 412 半小时内不碰 B 站 |
| 去重 | 已推荐 bvid 上限 500 |
| 零写入 | 对 B 站不产生任何写操作 |

## 能力与边界

| 能力 | 用途 | 收窄 |
|---|---|---|
| `bilibili` | 热门列表 / 元数据 / 字幕原文 | 宿主钉死 bilibili 域，GET only |
| `cron` | 每天 21:00 一轮 | 作息窗口 + 退避 |
| `send` | 日报 | 只发配置会话 |
| `storage` | 关键词 / 去重 / 退避戳（加密） | 不存视频正文 |
