# novel-desk（soapbot 插件）

私密小说写作台：设定卡（人物/世界观/规则）与章节草稿都存**插件加密 storage**，
`/nd-search` 按关键词检索设定，章节自动保存上一版、可恢复。改编自
mistnest/dsh-cuigengji-plugin（催更姬小说工作台，85★）。

## 与催更姬的差别（边界决定形态）

- **「AI 工具调用按需读设定」做不了**：那需要宿主的模型工具面（tools/MCP），
  soapbot 插件没有。确定性版 = 作者自己用 `/nd-search` 查设定；「模型按需读
  设定」登记为宿主 tools 设计输入（ADAPTATION.md 第七批）。
- **storage-only，不进宿主 kb**：小说设定通常私密，kb 是共享检索面——写进去
  就可能被别的会话召回。
- **检索是子串匹配**：原仓库的语义检索需要嵌入面，这里如实降级为精确子串，
  不假装智能。
- 情节画布 / 酒馆导入 / 剧情变量不做（画布是 UI 工程；酒馆迁移与其生态绑定）。

## 命令

| 命令 | 作用 |
|---|---|
| `/nd-card <名字> <内容>` | 新建/更新设定卡 |
| `/nd-card-list` / `/nd-card-show <名>` / `/nd-card-del <名>` | 管理 |
| `/nd-search <关键词>` | 全部设定卡子串检索（按需读取的确定性版） |
| `/nd-ch <章节名> <正文>` | 新建/追加章节（自动保存上一版，保 3 版历史） |
| `/nd-ch-list` / `/nd-ch-show <名> [字数]` / `/nd-ch-undo <名>` / `/nd-ch-del <名>` | 章节 |
| `/nd-stats` | 全库字数统计（字符数，如实标注不是 token） |

## 能力与边界

| 能力 | 用途 | 收窄 |
|---|---|---|
| `storage` | 设定卡 / 章节草稿（加密） | 卡 ≤200、章 ≤100、单文本 ≤20k 字符 |

无模型调用、无网络出站、无 cron、无 send——写作台是作者的工具，不是机器人的
人格行为。
