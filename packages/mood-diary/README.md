# mood-diary（soapbot 插件）

每晚 21:50 把当日交互统计折成一句心情日记（开心 / 热闹 / 平静 / 想念），写进插件
自己的加密 storage 时间线（保留 30 天）；`/mood` 看最近七天；纪念日当天主动说一句。
改编自 dsh-feiyu-mood（模型判心情）与 private_companion（每日反思 / 纪念日），
**走 soapbot 自己的路**：心情是事后日记，不注入 prompt——宿主温度管「关系亲疏」
（确定性、写入权只在管线），这里管「当日热闹程度」（插件 storage、硬编码分档）。

## 命令

| 命令 | 作用 |
|---|---|
| `/mood-on` | 开启（每晚记账 + 基调极端时主动一句 + 纪念日提醒） |
| `/mood-off` | 关闭（时间线保留） |
| `/mood` | 查看最近七天 |
| `/mood-forget` | 清空日记与统计 |

## 基调分档（确定性，硬编码）

当日消息条数：≥15 开心、6–14 热闹、1–5 平静、0 想念。没有模型调用——feiyu-mood
的「模型判心情 + 注入 systemPrompt.context」在 soapbot 会踩「插件状态进 prompt
权威」的边界，这里用日记式落法替代。

## 主动发言的克制

只发显式开启的会话；每日 ≤1 条；只在基调极端（开心 / 想念）或纪念日当天；
纪念日每年最多一次（年份标记防重）。

## 能力与边界

| 能力 | 用途 | 收窄 |
|---|---|---|
| `message` | 钩子计数 + 当日片段（前 60 字符，≤5 条） | 原文不落盘 |
| `storage` | 日记时间线 / 统计 / 纪念日（加密） | 只存元数据与短片段 |
| `cron` | 每晚 21:50 记账 | — |
| `send` | 基调极端 / 纪念日主动一句 | 只发开启的会话，每日 ≤1 条 |

无模型调用。心情不是命令、不是注入、不是温度——它是日记。
