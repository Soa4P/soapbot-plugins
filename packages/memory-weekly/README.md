# memory-weekly（soapbot 插件）

`/memweek`：把本周聊过的话题逐个丢进宿主记忆召回，按记忆 id 去重，整理成
「这周聊到的、还记得的事」。回应的是那句「怕新开一段对话之前说的还算不算数」——
回顾是你主动要的，不是机器人自称记得。

改编自 dsh-fish-memory（淡忘半衰期 / 证据式召回 / 事实键 latest-wins）与
private_companion（记忆反思）。**边界决定形态**：

- 召回权在宿主：插件只有 `ctx.memory.recall`（memory_read、每次重查能力、
  会话范围由宿主绑定的 caller 决定）。fish-memory 的淡忘半衰期、事实键
  latest-wins、每日配额是**宿主记忆层的设计输入**（ADAPTATION.md 第五批有登记），
  插件实现不了也不该实现。
- 召回结果没有时间戳，就不编造「X 天前」——时间感来自我们自己攒话题的钩子
  时间戳（「因 N 天前聊到 XX 想起」），这是仅有的诚实时间感。
- 没有 cron 推送：跨会话召回在 cron 里做不到（无 caller 即无会话范围），回顾
  必须由会话里的人主动触发。

## 命令

| 命令 | 作用 |
|---|---|
| `/memweek` | 用本周话题召回记忆，输出回顾（最多 12 条） |

## 能力与边界

| 能力 | 用途 | 收窄 |
|---|---|---|
| `message` | 攒本周话题片段（前 100 字符，≤20 条，14 天过期） | 原文不落盘 |
| `storage` | 话题片段（加密） | 只存片段与时间戳 |
| `memory_read` | 召回（每次调用重查能力） | 会话范围由宿主 caller 决定 |

无模型调用、无 cron、无 send。
