# qzone-composer（soapbot 插件）

每天 10:00 从 http 允许列表里的 RSS 源抓一条素材、确定性脱敏后起草一句话空间说说，
提醒到你开启的会话；**发布必须你敲 `/qzc-confirm`**——机器起草，人确认发布。
改编自 kakamiku/dsh-qzone 的素材链路与脱敏 scrubber；「cron 自动发帖」不改编，
因为它与宿主 qzone 网关的三重确认边界冲突（A12：启用 + 能力审批 + 逐条 confirm）。

## 命令

| 命令 | 作用 |
|---|---|
| `/qzc-set` | 开启（提醒发到当前会话） |
| `/qzc-off` | 关闭（草稿保留） |
| `/qzc-draft-now` | 现在起草一轮（不发布） |
| `/qzc-confirm` | 确认发布当前草稿（三重确认的最后一道） |
| `/qzc-drop` | 放弃当前草稿 |

## 与 dsh-qzone 的三个决定性差别

1. **不自动发帖**——cron 只起草；发布必须人工确认。
2. **素材只有 RSS**，且域名必须在操作者的 http 允许列表里（插件不能自己加源）。
3. **写失败不自动重试**——票据会掉（dsh-qzone 风控实测：retcode=10027、经典说说
   才发得出去）；重试是人的决定。

## 脱敏（确定性正则，命中即弃该素材）

手机号、身份证、QQ 号/群号形态的长数字串、Windows 路径、`key=/token=/secret=/password=`
凭据形态。宁缺毋滥——发出去的话是拿操作者账号说的。

## RSS 解析的安全边界

外部 XML 先拒 `<!DOCTYPE`/`<!ENTITY`（实体扩展炸弹）并限输入 512KiB，再交给标准库
解析器；标题剥标签、截 60 字符。

## 能力与边界

| 能力 | 用途 | 收窄 |
|---|---|---|
| `http` | 抓允许列表里的 RSS | 只 GET，域名由操作者决定 |
| `storage` | 草稿 / 每日额度（加密） | 草稿一条，发布即删 |
| `cron` | 每天 10:00 起草 | 每日起草 ≤1、发布 ≤1 |
| `send` | 草稿提醒 | 只发开启的会话 |
| `qzone_write` | 确认后的发布 | 宿主网关三重确认 + 每条 confirm=true |

无模型调用（dsh-qzone 的「按人设写一句话」需要模型面——起草模板是固定句式，
更自然的文案走人格卡演进）。
