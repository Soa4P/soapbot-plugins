# bili-card

群里有人贴 B 站链接时，回一张确定性的信息卡。

```
《标题》
UP 主：xxx · 科技 · 6:27
播放 1.2万 · 弹幕 100 · 点赞 200
https://www.bilibili.com/video/BV…
```

## 与上游的差异

参照 AstrBot 市场 `analysis_bilibili` 的机制，按本仓边界收窄：

| 上游 | 本插件 |
|---|---|
| 插件自己抓 view API | 宿主 `bilibili.view` surface 代解析代限流，插件只发目标只拿白名单字段 |
| 回复带封面图 | 纯文本卡（封面是 hdslb 热链，不进插件） |
| 无去重 | 会话 30 分钟 TTL 去重 + 每会话每分钟 2 张上限 |
| 解析小程序卡片 | 只认文本里的 BV/av/b23 链接 |

## 边界

- **无模型调用**：正则提取 → surface 取数 → 模板渲染，全确定性。
- **失败静默**：限流、解析失败、网络抖动都不回复、不刷日志——失败不是事件。
- **只读**：没有任何写面；发送走 SEND 能力的已观察会话白名单。
- **命令面留给宿主**：想主动查询用 `/bili`，本插件只管「有人贴链接」的被动卡。

## 能力

| 能力 | 用途 |
|---|---|
| `message` | 钩子里提取链接 |
| `bilibili` | `bilibili.view` surface（宿主 L2 client） |
| `send` | 回卡到当前会话 |
| `storage` | 会话级 TTL 去重（加密存储，只存目标串与时间戳） |
