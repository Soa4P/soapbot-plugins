# skill-tree（soapbot 插件）

把「我在学什么」做成一棵可点亮的技能树：前置锁定、进度私密、点亮只来自你自己。
改编自 zeroa234/cs-math-skill-tree（193 技能、262 条必须前置、证据先行、保守合并）。

## 命令

| 命令 | 作用 |
|---|---|
| `/tree-add <id> <名称> [必须前置] [推荐前置]` | 新增技能（前置当场拒环；引用不存在的 id 会被拒绝） |
| `/tree-done <id>` | 点亮（必须前置未齐硬拒绝；推荐前置只提示） |
| `/tree-undo <id>` | 取消点亮（连带撤下游依赖的点亮——保守合并的镜像） |
| `/tree` | 全树视图（✅ 已点亮 / ⭕ 可点亮 / 🔒 锁定） |
| `/tree-progress` | 进度统计 + 下一个可点亮 |
| `/tree-export` / `/tree-import <JSON>` | 导出/导入（保守合并：已有点亮不被覆盖） |
| `/tree-reset 确认` | 清空 |

## 与原仓库的差别（边界决定形态）

- **没有 AI 判定**：点亮只来自用户自己声明——「证据先行」在这里是「没声明就是
  没学会」，不自动认定部分掌握。
- **私密优先**：树与进度存插件加密 storage，不进宿主 kb（学习记录不想被别的
  会话召回）。
- **环在写入时拒绝**：原仓库在构建脚本检测环；这里 `/tree-add` 当场 DFS，成环
  的必须前置直接拒绝。
- 知识导览图/课程证据/在线资源不做（那是静态站点工程，且需要出站）。

## 能力与边界

| 能力 | 用途 | 收窄 |
|---|---|---|
| `storage` | 树与进度（加密） | 技能 ≤300；导出导入是显式命令 |

无模型调用、无网络出站、无 cron、无 send。


## 1.0.0：复习提醒（MAJOR——capabilities 加 cron/send）

- `/tree-review-set [天数]`：开启当前会话的复习提醒（默认每 7 天）。
- cron 每天 09:30：从点亮最早的技能里挑最多 3 条发提醒；提醒过的记 `reviewed`，
  7 天内不重复提醒（发送失败也记，7 天后自然重提）。
- `/tree-review-off`：关闭。

capabilities 加 cron/send 是 MAJOR（VERSIONING.md 规则）→ 1.0.0。
